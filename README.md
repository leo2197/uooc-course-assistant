# UOOC课程助手（Windows测试版）

视频静音2倍速、识别未完成课程、模型辅助测验、持久提交保护。Windows 10/11 x64，需要已安装Microsoft Edge。支持当前适配的UOOC学习页，不代表所有学校定制页面均可用。

[下载运行包](https://github.com/leo2197/uooc-course-assistant/releases) · [常见问题](FAQ.md)

## 第一次使用

1. 从Releases下载 **Windows-x64.zip**，右键“全部解压”。保留完整app文件夹，双击唯一的“启动.cmd”。不要在压缩包预览里运行。
2. **先选择模型服务。** 选择「1 GLM（推荐）」会预填官方API地址，填写自己的Key；选择「2 其他兼容服务」后填写API地址和Key，支持兼容Chat Completions的服务。模型ID可回车自动从服务商列表检测，或自行填写主答/裁决模型ID。调用费用以服务商为准。只有检测通过才替换旧设置。
3. 菜单选择开始，脚本打开专用Edge。**第一次请在网页本人登录，并完成安全验证。** 登录状态留在当前账号的本机浏览器资料中；以后优先复用，过期会提示重新登录。
4. 自动读取课程任务状态，列出未完成课程，**在脚本输入课程编号**；多门用空格分隔。也能选自动处理所有未完成课程。识别失败时可粘贴官方课程或学习页完整网址。
5. 保留脚本窗口查看进度。浏览器可以最小化，Ctrl+C停止。关闭浏览器会中止任务，已落盘的提交记录保留。

Windows运行包自带Node和依赖，无需安装Node。GitHub自动生成的Source code面向开发者，需安装Node.js 22+后运行npm ci。

## 主要功能

- **视频**：静音、2倍速；按平台任务勾选判断完成，已完成任务跳过。页面误跳时尝试返回原任务，恢复实际播放位置。
- **选课**：读取平台视频和测验任务数，识别未完成项目；已结束、尚未发布、状态未知的课程不自动开始。视频/测验完成不等于考试/作业或整课完成。
- **测验**：主答、复核和最终裁决；提交前逐题核对页面与原生选项模型。裁决不确定时可以在脚本确认，或接管网页作答后继续。
- **提交保护**：每卷尝试持久落盘，提交反馈不明时停止重交，避免重复消耗机会。不要删除data绕过保护。
- **登录与配置**：专用浏览器保存登录状态；新增账号使用独立浏览器资料和学习记录。新引导的API Key用当前Windows用户加密。多个角色使用同一模型时，不宣称独立模型投票。

UOOC测验可能只有一次机会，本工具保留不确定题确认流程，不套用其他平台可重练掌握度题的随机尝试方式。安全验证本人完成，不保证测验满分。不提供自动签到、UOOC评论或智慧树式掌握度功能。

## 再次运行与更换设置

再次双击启动.cmd，可开始/继续、修改模型或切换账号；重新开始会重新识别并编号选课。朋友请使用公开包独立配置，不能分享个人运行目录。

当前复用登录态，不承诺记住或自动填写每种登录方式的密码。旧本地config.txt仍兼容，其中旧明文账号和Key不会被擅自删除；该文件不在开源包中。

## 开发与构建

```
npm ci
npm test
npm run test:browser
npm start
```

离线测试使用模拟接口与页面，不需要真实账号或付费Key；设置UOOC_USERNAME=fixture、UOOC_PASSWORD=fixture、LLM_API_KEY=fixture后运行测试。不要对真实课程交卷验收。

`node build-public.cjs`按固定白名单生成Source.zip和Windows-x64.zip，扫描个人标识与密钥，校验官方Node运行时；`--source-only`只生成源码。dist/candidate-*保存候选、manifest和SHA256。绝不要整体提交运行目录。
